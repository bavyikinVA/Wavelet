# Wavelet Analysis

Инструмент для одномерного и двумерного вейвлет-анализа изображений.

## Режимы

- **1D-анализ** — существующее преобразование Морле отдельно по строкам и/или столбцам RGB-каналов. Поддерживает экстремумы, огибающие, KNN и межстрочную синхронизацию.
- **2D-анализ** — отдельное комплексное двумерное преобразование Морле по масштабам и ориентациям. Сохраняет карты модуля и фазы.

## Последовательность работы

1. Создать задачу.
2. Выбрать режим анализа.
3. Загрузить изображение.
4. При необходимости настроить цветовые каналы.
5. Задать масштабы.
6. Для 1D выбрать строки и/или столбцы; для 2D задать ориентации, центральную частоту и анизотропность.
7. Выбрать форматы результатов и нажать **«Запустить»**.

Все параметры хранятся отдельно в каждой задаче. Результаты создаются в отдельной папке в `Downloads`.

## 2D Morlet

Используется комплексный повёрнутый вейвлет

\[
\psi_{a,\theta}(x,y)=\frac{1}{a}
\left(e^{i\omega_0 x_\theta/a}-e^{-\omega_0^2/2}\right)
\exp\left[-\frac{1}{2}\left(
\frac{x_\theta^2}{a^2}+
\frac{y_\theta^2}{a^2\gamma^2}
\right)\right],
\]

где `a` — масштаб, `θ` — ориентация, `ω₀` — центральная частота, `γ` — анизотропность. Свёртка выполняется через FFT. При включённом GPU используется CuPy; при ошибке выполняется переход на CPU.
